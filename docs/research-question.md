# 研究问题

## 当前总问题

在联邦大语言模型参数高效微调中，如何在客户端数据异构、设备资源异构和隐私约束同时存在时，提升全局泛化、个性化性能和通信效率？

## 候选子问题

RQ1：统一聚合参数高效模块是否会在任务异构场景下损害部分客户端性能？

需要验证：
- 客户端数据分布差异越大，统一全局适配器是否越容易出现负迁移。
- 哪些客户端受损最明显。

RQ2：将适配器划分为全局共享、簇级共享和本地私有三部分，是否能降低跨任务干扰？

需要验证：
- 相比单一全局 LoRA，三层结构是否提升平均性能和尾部客户端性能。
- 相比纯个性化 LoRA，是否保留跨客户端知识迁移收益。

RQ3：异构 rank 或异构上传预算是否能在不明显降低性能的情况下降低通信成本？

需要验证：
- 不同客户端 rank 分配策略对性能、通信量、训练时间的影响。
- 弱设备客户端是否能参与训练而不是被排除。

RQ4：隐私保护机制对不同层、不同 rank 的影响是否不同？

需要验证：
- 统一加噪和分层/分块加噪的性能差异。
- 隐私预算变化对个性化性能和全局性能的影响。

## 证伪条件

如果出现以下结果，需要修改或放弃当前方案：
- 三层结构相比强基线没有稳定收益。
- 聚类或路由模块带来的收益小于其通信或计算开销。
- 隐私模块导致性能不可接受下降。
- 研究问题已被高质量近期文献完整解决。
