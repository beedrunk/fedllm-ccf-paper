# 项目约束

更新时间：2026-05-25

## 投稿目标

- 目标层级：CCF C 类期刊。
- 期刊语言：优先英文期刊。
- 计划周期：3 个月形成可投稿版本。
- 论文侧重点：算法创新和实验完整性。
- 风险偏好：基于已有框架做明确问题改进，争取 CCF C。
- 若实验不支持初始方案：接受及时换题。

## 资源约束

- 本地 GPU：用户描述为 4060，显存 32 GB。该信息需要后续用 `nvidia-smi` 核验。
- 服务器：无学校服务器；后期实验阶段可租用云服务器。
- 模型规模：开发和最小实验优先 1B 级别或更小；若租用服务器后资源允许，可补充更大模型或更多客户端实验。
- 每周投入：约 2 天。
- 联邦环境：接受模拟联邦实验，不要求真实多机器部署。

## 能力约束

- 目前不能独立完成完整 PyTorch/Transformers/PEFT/Federated Learning 改造。
- 尚无已有 FedLLM 代码基础。
- 需要全流程推进：文献、方案、代码、实验、写作、投稿准备。
- 项目最终需要可开源。

## 研究偏好

- 创新类型：系统/资源异构方向为主，但必须有清晰数学公式和优化目标。
- 隐私：不作为 3 个月主贡献，除非最小版本提前完成。
- 数据：英文公开数据集，偏教育场景。
- 实验：公开数据集、模拟客户端、可复现实验。

## 当前决策

主线暂定：

资源异构客户端下的自适应 Rank 个性化联邦 LoRA 微调。

不作为主线：

- 完整差分隐私会计。
- 真实多机器联邦部署。
- 7B 及以上模型训练。
- 大规模多领域评测。
