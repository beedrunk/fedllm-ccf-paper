# 数据集策略

## 当前决策

主实验不强制使用教育场景。

推荐策略：

- 主实验：使用通用英文 NLP 数据集，优先保证可复现、基线充分、评价指标清楚。
- 补充实验：选择一个英文教育相关公开数据集，作为应用场景展示。

## 为什么主实验不建议绑定教育场景

教育数据集的优点是应用背景清晰，但风险较高：

- 数据格式可能不适合统一的 LoRA 微调流程。
- 许可证、划分方式和评价指标可能需要额外处理。
- 教育任务可能更偏问答、评分或知识追踪，容易把论文主线从 FedLLM 算法带偏。
- 3 个月周期内，过早绑定垂直数据会增加不确定性。

通用 NLP 数据集更适合作为主实验，因为：

- 任务定义清晰。
- 基线容易复现。
- Non-IID 划分容易设计。
- 指标更直接。
- 更适合验证算法本身。

## 推荐主实验方向

优先级 1：文本分类

适合原因：
- 跑得快。
- 指标明确。
- 适合多客户端 Non-IID 划分。
- 有利于快速验证 FedLoRA 框架。

可选任务类型：
- 情感分类。
- 主题分类。
- 自然语言推理。

优先级 2：问答或阅读理解

适合原因：
- 更接近教育场景。
- 可以作为补充实验。

风险：
- 生成式评价更复杂。
- 训练和评估成本更高。

优先级 3：指令微调

适合原因：
- 更贴近 LLM。

风险：
- 实验慢。
- 指标容易不稳定。
- 需要更强算力和更严谨评价。

## 建议选择

主实验采用：

```text
通用英文文本分类 + 模拟 Non-IID 客户端
```

补充实验采用：

```text
英文教育问答或教育文本分类数据集
```

具体数据集必须经过许可证核验后再写入论文。
