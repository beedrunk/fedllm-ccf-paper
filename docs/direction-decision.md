# 选题方向决策

更新时间：2026-05-25

## 当前推荐方向

主实验方向：

```text
通用英文文本分类 + NLI 任务上的资源异构个性化 FedLoRA
```

补充实验方向：

```text
学生答案/教育文本分类相关公开数据集
```

## 为什么主实验建议选择通用 NLP

3 个月 CCF C 目标下，通用 NLP 比教育主实验更稳：

- 数据集更成熟。
- 评价指标更直接。
- Non-IID 客户端划分更容易。
- baseline 更容易复现。
- 训练成本更低。
- 更适合验证算法本身，而不是被教育任务建模细节分散。

## 推荐主任务优先级

优先级 1：文本分类

理由：
- 最容易快速跑通 FedLoRA。
- 可以直接报告 Accuracy、F1。
- 客户端 Non-IID 划分清晰。
- 适合做资源异构、rank、通信成本消融。

优先级 2：自然语言推理

理由：
- 任务更有语义难度。
- 适合证明方法不是只对简单分类有效。

风险：
- 训练和评估成本比普通分类更高。

优先级 3：问答或生成式任务

理由：
- 更接近 LLM 应用和教育场景。

风险：
- 指标复杂。
- 训练时间长。
- 对 3 个月周期不友好。

## 当前建议

主实验使用：

```text
文本分类 + NLI
```

补充实验使用：

```text
学生答案/教育文本分类
```

## 不建议作为主线

不建议把教育场景作为主实验，因为它会增加数据处理和任务定义风险。

不建议把生成式指令微调作为第一阶段主实验，因为评价不稳定、成本高，容易拖慢 baseline 建设。

不建议把隐私保护加入主贡献，因为会显著增加理论和实验负担。

## 需要后续核验

具体数据集名称、许可证、下载地址和划分方式必须在文献/数据核验阶段确认后再写入论文。
