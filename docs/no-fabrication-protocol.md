# 防编造协议

本项目所有论文内容按可信等级管理。

## 可信等级

| 等级 | 含义 | 是否可进入论文正文 |
| --- | --- | --- |
| L0 | 想法、猜测、待验证判断 | 不可 |
| L1 | 有来源但尚未阅读原文 | 不可 |
| L2 | 已阅读原文并记录页码、段落或公式 | 可作为背景，但需谨慎 |
| L3 | 已有多篇来源交叉支持 | 可作为相关工作或问题动机 |
| L4 | 已由本项目实验复现或验证 | 可作为本文实验结论 |

## 文献规则

- 禁止写入不存在的论文、作者、期刊、会议、年份、DOI。
- 禁止根据标题猜测论文内容。
- 禁止把二手综述中的说法直接当作原始证据。
- 每个关键文献结论必须进入 `literature/evidence-ledger.csv`。
- 对 arXiv 论文必须标注是否已经正式发表。

## 数据规则

- 数据集必须记录下载地址、许可证、版本、下载日期和预处理脚本。
- 不确定许可证的数据集不得用于投稿实验。
- 私有数据不得混入公开可复现实验，除非论文明确说明不可公开原因。

## 实验规则

- 实验必须先登记再运行。
- 每次运行必须记录模型、数据、划分、超参数、随机种子、硬件、代码版本和命令。
- 失败实验也要记录。
- 图表只能从结果文件或日志生成，不手工填写。

## 写作规则

正文中每个强主张都必须能映射到以下之一：
- `literature/evidence-ledger.csv` 的文献证据。
- `experiments/run-log.md` 的实验记录。
- `results/` 中可追溯的结果文件。

禁止写法：
- "大量研究表明"，但没有列出具体来源。
- "显著提升"，但没有统计检验或明确指标。
- "首次提出"，除非完成系统文献核验。
- "当前方法普遍忽略"，除非有明确比较表支撑。
