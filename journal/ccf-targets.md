# CCF 期刊目标

## 使用规则

不要凭记忆选择期刊。投稿前必须重新核验：
- 是否在当前 CCF 推荐目录中。
- 所属类别。
- 是否接收联邦学习、大模型或机器学习方向论文。
- 近年审稿周期。
- 是否需要开放数据或代码。
- 是否有版面费。

## 当前策略

用户目标是 CCF C 类英文期刊，周期 3 个月。候选期刊不在本文件中凭记忆填写，必须在投稿准备阶段从 CCF 官方推荐目录和期刊官网重新核验。

初步倾向：
- 优先选择机器学习、人工智能应用、自然语言处理或计算机教育技术交叉方向中接收算法和实验论文的英文期刊。
- 若主方法更偏资源异构和联邦系统，考虑系统或网络方向 C 类期刊是否更匹配。
- 若教育数据只作为补充实验，不把期刊范围限定为教育技术。

## 选择标准

- 主题匹配优先于分区。
- 实验规模和创新强度决定冲 B 还是稳 C。
- 若方法偏系统框架，优先考虑数据库、网络、软件或系统相关期刊是否更匹配。
- 若方法偏机器学习算法，优先考虑人工智能和机器学习相关期刊。
