# 导师反馈 v1

日期：2026-05-25

## 原始要点整理

1. 主线收敛到资源异构个性化是契合的。隐私、多模态、聚类可作为加分扩展，不作为主线，避免贡献分散。
2. 推荐期刊：`Computer Networks` 与 `Journal of Network and Computer Applications`。期刊可以排序，先投更好的。
3. 需要进一步加强理论分析或方法差异，但不必做过强理论。建议至少补充：
   - 聚合偏差的形式化描述。
   - 资源分配目标的形式化描述。
   - 借鉴 FedHL、EcoLoRA、FedEx-LoRA 等近期工作的分析范式。
4. 与 FLoRA、FlexLoRA、AFLoRA 的差异应更清晰。建议以如下组合作为主线叙事：
   - 个性化结构：共享 LoRA + 私有 LoRA。
   - 资源分配策略：预算感知 rank 或上传预算分配。
   - 稳健聚合：减少异构更新和异常客户端对共享 LoRA 的干扰。
   - 统一评测：性能、个性化、通信、差异性实验。
5. 文本分类 + NLI 主实验符合定位，但需要同步说明 Non-IID 构造与资源预算划分方案，确保复现性。
6. 论文不宜只强调系统评测而缺少方法学与学习系统理论。可对照 Neurocomputing 论文的写法，判断方法深度和理论系统共设计是否达到期刊要求。
7. 大量文献阅读是必要的。方法深度与理论系统共设计的能力短期形成不易，需要专门安排文献阅读和方法差异分析。

## 已采纳修改

- 主线固定为：资源异构个性化 FedLoRA。
- 主线叙事改为：共享/私有个性化结构 + 资源分配策略 + 稳健聚合 + 统一评测。
- 隐私、多模态、聚类移动到扩展或讨论，不放入主贡献。
- 开题报告增加轻量理论分析章节。
- 开题报告增加 Non-IID 构造和资源预算划分方案。
- 期刊策略改为：优先评估 Computer Networks，其次 JNCA，Neurocomputing 作为方法深度对照和备选。

## 待继续核验

- `ECLoRA` 是否指 `EcoLoRA`。当前先按 `EcoLoRA` 作为通信高效 FedLoRA 相关工作记录，但不把二者混同写入论文。
- Computer Networks、JNCA、Neurocomputing 的 CCF 类别和投稿要求需要投稿前从 CCF 官方目录与期刊官网再次核验。
- FedHL、EcoLoRA、FedEx-LoRA 需要精读并建立阅读笔记，不能只依赖摘要。
