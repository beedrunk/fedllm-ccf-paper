# 自查清单

## 文献自查

- [ ] 所有参考文献真实存在。
- [ ] 所有引用字段准确。
- [ ] 所有关键主张都有 evidence id。
- [ ] 没有使用无法核验的二手说法。
- [ ] 没有未经证明的 "首次"、"显著"、"普遍"。

## 实验自查

- [ ] 所有实验已登记。
- [ ] 所有结果能追溯到命令和配置。
- [ ] 至少报告平均值和方差，或说明为什么无法多次运行。
- [ ] 基线实现公平。
- [ ] 消融实验能对应每个模块。
- [ ] 负面结果没有被隐藏。

## 写作自查

- [ ] 摘要中的每个结果都能在实验表中找到。
- [ ] 引言中的痛点有文献或实验支撑。
- [ ] 贡献与已有工作差异清楚。
- [ ] 方法描述足以复现。
- [ ] 局限没有被回避。

## 投稿自查

- [ ] 已核验目标期刊 CCF 类别。
- [ ] 已使用期刊模板。
- [ ] 已检查匿名要求。
- [ ] 已准备 cover letter。
- [ ] 已检查图表分辨率。
- [ ] 已检查伦理、隐私和数据可用性声明。
