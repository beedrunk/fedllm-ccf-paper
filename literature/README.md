# 文献管理

本目录只记录真实、可核验文献。

## 文件说明

- `search-log.md`：检索记录，包括检索日期、数据库、关键词和筛选标准。
- `evidence-ledger.csv`：可进入论文的证据台账。
- `reading-notes-template.md`：单篇论文阅读笔记模板。
- `seed-keywords.md`：起步检索关键词。

## 文献进入流程

1. 先在 `search-log.md` 记录检索式。
2. 找到文献后核验标题、作者、年份、来源和链接。
3. 阅读原文后复制 `reading-notes-template.md` 建立笔记。
4. 只把已理解的事实写入 `evidence-ledger.csv`。

## 不允许

- 不允许把 AI 生成的参考文献直接放入论文。
- 不允许只看摘要就写相关工作细节。
- 不允许用无法打开或无法核验的链接支撑关键结论。
